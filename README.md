# 👨‍💼 Employee Management System

A Full Stack Employee Management System built using **Spring Boot**, **React JS**, **MySQL**, and **REST APIs**.

This application helps organizations efficiently manage employee records through a modern web interface with complete CRUD operations.

---

## 🚀 Features

### Employee Management

* Add Employee
* Update Employee Information
* Delete Employee
* View Employee Details
* View All Employees
* Responsive User Interface

### Backend Features

* RESTful APIs
* Spring Data JPA
* Exception Handling
* Layered Architecture
* MySQL Integration

### Frontend Features

* React Components
* Axios API Calls
* Form Validation
* Dynamic UI Updates

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/maramsivaramakrishnareddy/employee-management-system.git
```

### Backend Setup

```bash
cd ems-backend
mvn spring-boot:run
```

### Frontend Setup

```bash
cd ems-fullstack
npm install
npm start
```
